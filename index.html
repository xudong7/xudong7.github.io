About

Dong Xu

Undergraduate Researcher · Incoming M.Eng. Student

Sun Yat-sen University · School of Software Engineering · SYSUSELab

I work on LLM4SE and AI4SE: using large language models and AI to understand, generate, test, and maintain software systems.

I am an undergraduate researcher at Sun Yat-sen University, affiliated with SYSUSELab, and will join the School of Software Engineering as an M.Eng. student in September 2027. My research interests span LLM4SE, AI4SE, intelligent software engineering, repository-level code intelligence, and code graphs.

More broadly, I am interested in AI-powered methods and tools across the software lifecycle, including structured code representations, automated maintenance, and agentic developer tools for large software systems.
